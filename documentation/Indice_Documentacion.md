# Documentación Técnica — Nexus-Q

Esta carpeta centraliza la documentación técnica oficial del proyecto.

## Índice de contenidos

- `architecture/`
  - `Stack_Tecnologico.md`: stack tecnológico y decisiones de plataforma.
- `testing/`
  - `Plan_de_Pruebas.md`: plan de pruebas manuales y criterios de aceptación.
- `compliance/`
  - `Cumplimiento_ISO.md`: informe de alineación normativa (ISO/IEC 25010, ISO 9001, ISO/IEC 27001).
- `quality/`
  - `Guia_Codigo_Limpio.md`: guía de código limpio y mantenibilidad.
  - `Estandares_Codificacion.md`: estándares de codificación y convenciones del repositorio.

## Convención

Toda nueva documentación técnica debe incorporarse dentro de `documentation/` en la categoría correspondiente.
